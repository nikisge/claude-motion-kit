# Freigabekarte (eine pro Generierung)

Liegt in `projects/<name>/karten/<shot>.md`. Der Mensch bekommt eine kompakte Karte, keinen Fragenkatalog, und gibt
genau diese Karte frei. Bei Batches (z. B. 4 Requisiten-Bilder) ist der Batch ausdrücklich benannt.

- Auftrag / Zweck (welche Storyboard-Zeile):
- Status: VORGESCHLAGEN / FREIGEGEBEN / GESTARTET / FERTIG / ANGENOMMEN / VERWORFEN
- Art: Bild, Video, 3D, Audio, Upscale; genau eine Ausgabe oder benannter Batch
- Modell und geprüfte Parameter (Auflösung, Dauer, Entwurf ja/nein, Ton aus):
- Referenzdateien mit Rollen (Figur, Ort, Requisite, Startbild, Endbild, Bewegungsquelle):
- Kamera: Position, Blickrichtung, Ausschnitt, Optik, Licht (Skizze, wenn Blickachsen heikel sind)
- Genau eine Handlung bzw. der statische Zustand:
- Vollständiger Prompt (Englisch):
- Preis laut Preisabfrage, Obergrenze, Summe im Film-Ledger danach:
- Freigabe (wer, wann, Umfang):
- Job-ID, Ergebnisdatei, tatsächlich abgebuchte Credits:
- Prüfung am Kontaktbogen (Hände, Blickachse, Form, Schrift, Stützen), brauchbare Sekunden, Entscheidung:
